## ✨ Features

- **Modern UI/UX Design:** A sleek, dark-themed interface accented with a vibrant hot-pink color palette.
- **Interactive Particle Background:** Integrated `particles.js` for a dynamic and engaging background effect.
- **Floating Tech Sidebar:** A sticky right-hand sidebar featuring my core tech stack with smooth, pure-CSS tooltips on hover.
- **Smooth Scrolling Navigation:** Left-aligned, icon-based sidebar navigation that highlights the active section as you scroll.
- **Responsive Layout:** Built with CSS Flexbox and Grid to ensure a flawless experience across desktops, tablets, and mobile devices.
- **Dynamic Timelines & Progress Bars:** Visually appealing structures to display professional experience and skill proficiency.
- **Project Showcase:** A structured grid layout highlighting enterprise applications and tools I've engineered, complete with technology tags.

---

## 🛠️ Tech Stack Used

This portfolio is built with performance and simplicity in mind, utilizing core web technologies without the overhead of heavy frameworks:

- **HTML5:** Semantic markup for structure.
- **CSS3:** Custom properties (variables), Grid, Flexbox, pure CSS tooltips, and responsive media queries.
- **Vanilla JavaScript:** For scroll spy (active navigation links) and initializing the particle background.
- **Particles.js:** Lightweight JavaScript library for creating particles.
- **Icons:** [Devicons](https://devicon.dev/) (for tech stack logos) and [FontAwesome](https://fontawesome.com/) (for UI icons).
- **Typography:** 'Poppins' from Google Fonts.
